## How to replace this entry

- Drop your real gif into `PreviousCreations/assets/`
- Duplicate this file, rename it to something like `Your-Title.txt`
- Update `TITLE`, `GIF_URL`, and this popup text
- Add the new filename to `manifest.txt` — where you put it in that list
  is where it'll appear on the page (top of the list = shown first)
- Delete this example file (and remove it from the manifest) once you
  don't need it as a reference anymore
